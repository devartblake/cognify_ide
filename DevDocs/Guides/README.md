# Cognify IDE User Guides

How to use Cognify IDE, in the order you'll likely need it. The **Get Started with Cognify IDE** walkthrough, which opens on first launch (and from **Help > Welcome**), links to each guide.

| Guide | What it covers |
|---|---|
| [Create a project](CREATE_A_PROJECT.md) | The four templates (FastAPI, Next.js, ASP.NET Core, Flutter for the web), **Cognify: New Project...**, and what a new project contains. |
| [Environments](ENVIRONMENTS.md) | Building on this machine or in a Dev Container: **Cognify: Check Environment**, installing a missing tool, Docker, and troubleshooting. |
| [Run and preview](RUN_AND_PREVIEW.md) | **▶ Run**, the preview beside your code, Stop, and what to do when the app doesn't start. |
| [Ask Cognify](ASK_COGNIFY.md) | `@cognify /explain`, `/guide` and `/fix` (and `/review`), the editor shortcuts, and privacy. Needs a GitHub Copilot sign-in. |

What Cognify doesn't do yet is in [`KNOWN_LIMITATIONS.md`](../../KNOWN_LIMITATIONS.md).
