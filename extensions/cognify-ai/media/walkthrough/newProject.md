# Create a project

**Cognify: New Project...** asks four questions, then creates the project and opens it.

1. **Template:** FastAPI, Next.js, ASP.NET Core, or Flutter (web). Each one says whether this machine has what it needs.
2. **Name:** the folder is named after it.
3. **Location:** the folder the project folder goes in. Cognify never writes into a folder that already has files.
4. **Environment:** build, test and run on **this machine**, or in a **Dev Container** that has the tools. You keep editing on this machine either way. The Dev Container option needs Docker.

Every template comes with a test, a README that says how to build, test and run it, and a Dev Container preset.

Read the guide: [Create a project](https://github.com/devartblake/cognify_ide/blob/main/DevDocs/Guides/CREATE_A_PROJECT.md).
