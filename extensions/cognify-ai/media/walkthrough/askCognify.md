# Ask Cognify

Three ways to get help, in Chat or from the editor:

- **Explain:** right-click code or an error and choose **Explain with Cognify**, or ask `@cognify /explain`.
- **Guide Me:** ask `@cognify /guide` followed by what you want to do, for example `@cognify /guide add a page that lists users`. You get small numbered steps that use your project's own commands.
- **Fix It:** use **Fix with Cognify** on an error (the light bulb), or ask `@cognify /fix`. Cognify explains the error and proposes a fix. You decide whether to apply it.

Cognify never changes your files or runs commands by itself.

Read the guide: [Ask Cognify](https://github.com/devartblake/cognify_ide/blob/main/DevDocs/Guides/ASK_COGNIFY.md).
